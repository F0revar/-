# 额度气象站

追踪 Tibo（[@thsottiaux](https://x.com/thsottiaux)）公开动态的轻量中文消息站。每日额度消息优先，提供可追溯的事件、原帖上下文、本地补录和两个 RSS。

## 本地查看

已附带一次真实公开采集的快照。可以直接打开 [site/index.html](site/index.html) 查看；离线打开不更新上游数据。需要正常 HTTP 预览时，安装 Node.js 24 或更新版本，在本项目目录运行：

```powershell
npm start
```

在浏览器打开终端打印的本机地址，默认端口 8787。停止终端进程即停止预览。没有第三方运行依赖，不需要 `npm install`。

## 更新与补录

```powershell
# 联网读取免费公开来源，更新真实快照和 RSS
npm run collect

# 将原帖重新查询并校验后，补进公共档案
npm run import -- https://x.com/thsottiaux/status/2110618507276886392

# 验证数据处理规则
npm test

# 在采集后生成静态站
npm run build
```

网址仅作原帖补录命令的实参示例。补录成功不代表全量时间线检查成功。不要并发运行多个采集或补录进程；GitHub 工作流已设串行组，本地操作由使用者串行执行。

本机检查点保存在 `.state/state.json`（忽略提交）。采集失败会保留已存帖子，页面显示失败/较旧状态，进程返回退出码 2；不会用示例内容填充。重叠读取最近 72 小时以检查编辑，达到分页上限时不推进游标。免费源仍可能漏帖，未返回旧帖不视为删除。

网页的“补录原帖”先保存到当前浏览器，始终标为待核实，不进入公共 RSS；可导出 JSON 备份。公共发布须用上述命令或 GitHub 手动工作流重新查询原帖，不能直接把手工正文变成已确认事实。浏览器本地存储不可用时会明确报错。

## GitHub 免费运行

本项目目录的内容应作为仓库根目录上传，保留 `.github/workflows/update.yml`。以下是部署准备步骤；配置已提供，GitHub 上的实际执行与 Pages 权限须另行验证。

1. 选择一个公开仓库，默认分支为 `main`；公开内容仅包含本项目源码与公开帖子，不上传 `.state` 或浏览器补录文件。
2. 在仓库 Settings → Pages，把 Source 设置为 **GitHub Actions**；确认仓库/组织允许工作流写入内容和部署 Pages。
3. 在 Actions 中选择 **Update quota weather**，手动运行一次；首次保持 `post_url` 为空。
4. 工作流先建立独立的 `quota-state` 状态分支、读取免费源并生成 `dist/`，再检查 Pages 并部署。即使 Pages 尚未启用，已采集状态也会保存，工作流会明确提示启用设置。站点根地址按免费的平台域名和仓库子路径生成；此版本不使用自定义域名。
5. 验证首次工作流结果、正式网页地址、两个 RSS 与来源时间。此后 cron 为每小时第 17 分钟（UTC；相对北京时间同样是每小时第 17 分钟）。调度有延迟可能，不承诺固定送达时间。

人工补录时再次手动运行工作流，在 `post_url` 填入 Tibo 原帖链接。该链接经环境变量传递给校验器，不直接拼接到 shell 命令。无需 X Cookie、OpenAI API Key 或单独创建 GitHub PAT。

公开仓库长时间无活动时 GitHub 可能停用定时工作流；需要查看 Actions 状态并在必要时恢复。来源读取失败时，工作流会先发布保留历史的来源状态，再标记失败。状态分支写入或 Pages 部署失败则是独立故障，不能因为本地测试成功而视为云端已打通。

## 订阅与使用边界

- [daily.xml](site/daily.xml)：按北京时间分日的滚动中文简报，每日一个稳定 GUID，精选最多五条；不是固定时间发送的邮件。
- [feed.xml](site/feed.xml)：额度事件，包含预告、完成声明及待核实状态；同一事件修订沿用 GUID，阅读器不一定再次提醒。
- 本地地址不能供外部阅读器订阅。部署后从网页“订阅 RSS”复制正式地址。
- 天气表示公开公告状态，不读取个人账户，也不推断个人额度已恢复。
- 中文额度信息来自规则模板；复杂功能消息保留原文。分类不保证完全准确，适用产品或套餐不明确时不猜测。
- 事件来源包含本人正文与独立的引用/回复关系，其他作者的文字不会直接作为 Tibo 的完成声明；预告到期也不自动确认。

具体费用、节省措施与核价来源见 [COSTS.md](COSTS.md)；默认金额及核价日期以 [成本配置](config/costs.json) 为准。第三方代码来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
